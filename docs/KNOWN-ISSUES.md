# Открытые проблемы и план

## 1. Подтормаживания на приставке (главное, открыто с v1.10)

**Симптом.** Видео периодически замирает. В диагностике (кнопка Вверх) оценка сети ~0.8–1.1 Мбит/с,
запас буфера ~2 с. Раньше на той же приставке мерили 27–37 Мбит/с. Сайт в браузере на ПК в той же домашней
сети идёт без зависаний. PeersTV на приставке тоже работает гладко (другой источник).

**Что уже исключено / сделано.**
- Качество понизить нельзя: у канала один вариант 1080p.
- Два сервера (`tvcdnpotok.com`, `tvlife.live`), переключение работает — не помогло заметно.
- Глубокий буфер и отставание 20 с от эфира (v1.15) — не помогло: буфер просто не успевает наполняться.
- Wi-Fi выключается при наличии кабеля (v1.11), но стоит проверить, что поток реально идёт по кабелю.

**Гипотезы.**
- Сервер режет скорость по UA/заголовкам (у плеера UA, с которым была получена ссылка).
- Стандартный `HttpURLConnection` на Android 7 медленный/без keep-alive; OkHttp может быть быстрее.
- Трафик идёт по Wi-Fi, а не по кабелю (или кабель на 10 Мбит/с, плохой контакт).
- Сегменты качаются по одному последовательно, а задержка (RTT) до сервера большая.

**План (следующий шаг).** Добавить в диагностику тест скорости: скачать один и тот же сегмент из текущего
плейлиста разными способами и показать Мбит/с для каждого:
1. текущий способ (те же заголовки, что у плеера);
2. UA современного Chrome;
3. OkHttp (`media3-datasource-okhttp`) вместо `DefaultHttpDataSource`;
4. отдельно по кабелю и по Wi-Fi (через `Network.openConnection` для каждой сети);
5. оба сервера.
Затем переключить плеер на самый быстрый способ. Владелец присылает фото экрана с диагностикой.

**Настроение владельца.** Был сильно раздосадован долгими экспериментами (2026-10-19). Предлагать
изменения, которые проверяются за одну установку, и объяснять коротко.

## 2. Картинка мягче, чем в PeersTV (частично)

Выход приставки был 720p50; владелец выставил HDMI 1080P_60Hz (совет — 1080P_50Hz, поток 25/50 к/с).
Tunneled playback выводит видео в 1080. Android API на этой прошивке не сообщает реальный HDMI-режим.
Сравнить с PeersTV можно по его «Техническая информация» в настройках.

## Полезные факты

- Ссылка на поток содержит токен `wmsAuthSign`, живёт около часа; приложение само обновляет.
- Песочница агента обычно не достаёт до `telik.live` и `dl.google.com` — проверять только через Actions
  и на приставке.
