# Приставка MXQ Pro 4K и окружение владельца

- SoC Amlogic, 32-битный ARM (`armeabi-v7a`), **Android 7.0 (API 24)**; прошивка показывает «Android 11.1» — это неправда.
- Нет Google Play. Системный WebView — **Chrome 52**, обновить без root нельзя.
- Интерфейс (UI-плоскость) — 1280x720; Android `Display` API сообщает только режим 720p50 даже при HDMI 1080p.
  Видео в tunneled-режиме выводится на отдельную видеоплоскость в полном разрешении.
- HDMI-режим через sysfs (`/sys/class/display/mode`) из приложения не читается.
- Прошивка включает Wi-Fi при каждой загрузке, даже при подключённом кабеле (поэтому `WifiGuard`).
- Памяти мало: тяжёлые движки (GeckoView в TelikIVI) выгружаются системой, если параллельно работает плеер.
- Телевизор — 1920x1080.
- Пульт ДУ: D-pad, OK, Назад, Menu. Можно подключить USB/беспроводную мышь.
- Установка APK: флешка + файловый менеджер, или `adb install -r`.
- Сеть: домашняя, кабель (Ethernet) + Wi-Fi. На ПК в той же сети сайт играет гладко.
