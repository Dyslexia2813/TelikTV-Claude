# Связанные проекты и материалы

## TelikIVI (IVI-LiveNature)

https://github.com/Dyslexia2813/TelikIVI — второе приложение для той же приставки: канал «Живая природа»
на ivi.ru (нужна подписка, вход через кнопку «Войти» на сайте).

- Пакет `tv.telik.ivi`, ветка `main`, версия 0.12, артефакт `IVI-LiveNature-apk-<версия>`.
- Страница сайта открывается во встроенном GeckoView 144 (последний для Android 7), сам поток играет
  нативный Media3 с Widevine.
- Статус (2026-11-04): работает, 1920x1080, Вверх — качество авто/максимум. Картинка «квадратнее», чем
  в PeersTV (вероятно, низкий битрейт у ivi), владелец принял как есть и закрыл тему.
- Подробности — в `AGENTS.md` того репозитория.
