## Ключевые решения

- **Нативный плеер вместо WebView-плеера** — WebView 52 на приставке не обновить без root, а современный JS
  сайта на нём не работает. Обёртка над страницей осталась только как запасной режим.
- **Достать ссылку из HTML плеера** надёжнее, чем ждать, пока плеер страницы сам её запросит.
- **UA современного Chrome** — `cdntvmedia.com` режет старые UA ответом 403.
- **Tunneled playback** — единственный способ получить полное 1080p на этой приставке: интерфейс у неё 720p.
- **Без тяжёлых библиотек** (ТЗ): нет AppCompat, Kotlin, UI-модуля Media3.
- **Версия в имени APK/артефакта** — просьба владельца (2026-10-23), чтобы не путать сборки.
