# Исходное техническое задание

Перенесено из `task.docx` (файл проекта) без изменений по смыслу.

Нужно создать максимально лёгкое и быстрое Android TV приложение для ТВ-приставки MXQ Pro 4K TV BOX.

Основная задача приложения:
- сразу после запуска автоматически открывать и воспроизводить потоковое видео с веб-страницы:
https://telik.live/zhivaya-priroda.html

Ключевые требования:

## 1. Архитектура

- Максимально простое приложение.
- Без лишних экранов, меню и логики.
- После запуска приложение должно сразу открывать поток.
- Приложение должно работать как «обёртка» над веб-страницей или напрямую над видеопотоком.
- Приоритет: минимальное потребление RAM и CPU.

## 2. Платформа

- Android TV / Android Box.
- Совместимость с Android 7–10.
- Устройство: MXQ Pro 4K TV BOX.
- Управление только с пульта ДУ.

## 3. Производительность

- Очень быстрый старт приложения.
- Минимальный APK размер.
- Минимальная нагрузка на слабое железо.
- Без анимаций и тяжёлых библиотек.

## 4. Воспроизведение видео

- Видео должно запускаться автоматически.
- Полноэкранный режим.
- Без отображения браузерного интерфейса.
- Без адресной строки.
- Без возможности перейти на другие сайты.
- Желательно скрыть все элементы страницы кроме самого видео.
- Если возможно — извлекать прямую ссылку на поток и воспроизводить (в оригинале фраза оборвана; по смыслу — воспроизводить её напрямую).

## 5. Автозапуск и стабильность

- При ошибке загрузки автоматически перезапускать поток.
- При потере интернета пытаться переподключаться.
- Запретить переход устройства в sleep mode.

## 6. Интерфейс

- Чёрный фон.
- Без кнопок.
- Без настроек.
- Без splash screen.
- Максимально минималистично.

## 7. Дополнительно

- Отключить масштабирование.
- Заблокировать поворот экрана.
- Landscape orientation only.
- Hide system UI / immersive fullscreen.
- Поддержка аппаратного декодирования видео.

## 8. Приоритет реализации

- скорость;
- стабильность;
- минимальная нагрузка на слабую приставку.

## 9. Для ориентировки:

Приставка довольно слабенькая но установленное на неё приложение PeersTV (`Peers.TV-7.19.2.apk` лежит в файлах проекта, в репозиторий не кладётся) без всяких проблем воспроизводит потоковое видео.
