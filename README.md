# TelikTV

Минимальное Android TV приложение для приставки MXQ Pro 4K TV BOX (Android 7–10).
Сразу после запуска открывает и показывает поток с https://telik.live/zhivaya-priroda.html.

## Как скачать APK

1. Вкладка **Actions** → последняя успешная сборка **Build APK** → блок **Artifacts** → `TelikTV-apk` (внутри zip лежит `TelikTV.apk`).
2. Или поставить тег `v1.0` (`git tag v1.0 && git push --tags`), тогда APK появится во вкладке **Releases** с прямой ссылкой.

Установка: скопировать `TelikTV.apk` на флешку и открыть файловым менеджером на приставке
(или `adb install -r TelikTV.apk`). Все сборки подписаны одним ключом, поэтому новая версия ставится поверх старой.

## Как работает

* Один экран, без меню, кнопок, настроек и splash. Чёрный фон, только альбомная ориентация, полноэкранный режим без системных панелей, экран не гаснет.
* При запуске страница открывается в скрытом браузере, приложение ловит прямую ссылку на поток (`.m3u8`), которую запрашивает плеер страницы, закрывает браузер (освобождает память) и играет поток нативным плеером Media3/ExoPlayer с аппаратным декодированием.
* Ссылка запоминается, следующий запуск сразу стартует видео без загрузки страницы. Если ссылка протухла, приложение само получит новую.
* Если прямую ссылку поймать не удалось, на экране остаётся сама страница, на которой скрыто всё, кроме видео.
* Ошибки и зависания потока: автоматический перезапуск. Пропал интернет: переподключение, как только сеть вернётся.
* Переходы на другие сайты заблокированы.

Пульт: **OK** перезапускает поток, **Назад** выходит из приложения.

## Сборка

Собирается GitHub Actions (`.github/workflows/build.yml`) на каждый push. Локально: `./gradlew assembleRelease` (нужен Android SDK, JDK 17).

Ключ подписи `app/release.keystore` (пароль `teliktv`) лежит в репозитории специально, чтобы обновления ставились поверх. Для приложения в магазине его стоит заменить на свой и передать через переменные окружения `SIGNING_STORE_FILE`, `SIGNING_STORE_PASSWORD`, `SIGNING_KEY_ALIAS`, `SIGNING_KEY_PASSWORD`.
